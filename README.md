# Wikcia website

Public presentation of Wikcia, the creative and business automation software by Love & Pixels. This repository contains the Vite and React website; it is not the distribution repository for the desktop application or its inference runtime.

## Development

Use Node.js and the dependency versions in the repository lockfile. Run `npm ci`, `npm run dev` for local development, `npm run build` for the production bundle, and `npm run test` for the existing regression suite.
