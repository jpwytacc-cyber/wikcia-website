# Wikcia — a working imagination

## Direction
An editorial **Decide / Learn** surface with a secondary **Explore / Make** experience. Warm paper and precise ink; citron as a signal rather than decoration. The supplied dimensional ribbon logo is the source of the sculptural vocabulary. Space Grotesk is locally hosted alongside Instrument Serif italic; the SIL OFL licences travel with the fonts.

## What changed
- An asymmetric introduction with an original, inspectable ribbon sculpture.
- A real browser-only SVG design workbench, explicitly not AI inference.
- Workflow explanations, not simulated job logs.
- Genuine screenshots of the public Love & Pixels, ONYX and Bella sites, with concept disclosures and direct links.
- Individually composed capability, product, toolkit, notes, about, FAQ and contact pages.
- An accessible native-dialog site finder and mobile navigation.
- An honest email-draft composer in place of the old form that falsely claimed to send a message.

## Boundaries
The public website is not an AI chat endpoint, application launcher, hosted terminal, customer booking service or public installer. The portfolio does not imply measured commercial results. Availability of a product capability depends on the installed environment, configuration, credentials and permission. Local inference does not make cloud conversations private.

## Design self-audit
The rejected edition used a centered oversized hero, violet effects, an equal-weight icon feature grid and ornamental metrics. The replacement deliberately changes composition instead of merely recolouring those components: a light editorial opening, an interactive making surface, a process inspector, staggered authentic project previews and a restrained signature footer. No feature icon toppers, accent rails, invented metrics, fake chat, stock-photo project placeholders or blurred gradient surfaces.

## Development
- `npm run dev` starts Vite.
- `npm run typecheck` checks all TypeScript sources.
- `npm run lint` uses the project's existing TypeScript-based lint gate (not an ESLint claim).
- `npm test` exercises pure generator and structural invariants.
- `npm run build` creates the production artifact.
- `npm run preview -- --host 127.0.0.1 --port 4197 --strictPort` serves it for acceptance.
- `npm run test:e2e` runs route, responsive, navigation, accessibility and interaction acceptance. Set `WIKCIA_TEST_BASE` for a deployed origin and `WIKCIA_TEST_OUTPUT` for receipts. On Windows the harness uses the installed Edge executable with an isolated profile; other hosts use an installed Playwright Chromium.
